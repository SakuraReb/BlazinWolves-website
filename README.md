# BlazinWolves-Website

The public website for **BlazinWolves™** — Sakura Noctis Vale, Alpha: the pack roster, About Sakura, her music, her books, and the door into the den.

- `index.html` is the whole site: one self-contained page (inline CSS/JS, no external images or dependencies), built in the pack's neon-pink-and-black style with a CSS pink moon and drifting cherry blossoms.

## Deploy

Served by **GitHub Pages** from the `main` branch, root folder (`/`). Push to `main` and Pages updates automatically.
